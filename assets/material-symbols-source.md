# Material Symbols Outlined

This bundled font preserves the project's existing Material Symbols icon system when the Google Fonts CDN is unavailable.

- Source: https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:wght,FILL@100..700,0..1&display=swap
- Font version: v380, variable weight 100–700, FILL 0–1.
- Upstream: https://github.com/google/material-design-icons
- License: [Apache 2.0](material-symbols-LICENSE.txt).

No new icon library is introduced. Existing `material-symbols-outlined` names and filled states continue to use the same font.
