# 国内视频配乐曲库与接入调研

调研日期：2026-10-26。目标：为视频工作流补充适合中文内容、中国风、古风和民族器乐的来源；核实官方授权及自动搜索、下载的可行性。

## 建议

当前优先提供爱给网、100Audio、猴子音悦的官网选曲入口；下载已获许可的音频后，通过现有本地导入进入配乐管理弹窗。Openverse 可保留为补充来源。上述国内站点本次均未取得可供本应用使用的官方公开搜索、下载 API 文档，不能把网站内部请求当作对外 API，也不能宣称已经实现站内检索和自动下载。

本报告未做曲库逐首比较，不能认定任何一家覆盖全部中国歌曲。以下区分已经核实的事实与接入建议。

## 如果需求是流行歌曲，而非配乐素材

QQ 音乐、网易云一类听歌平台，与上述面向视频制作的配乐素材库，覆盖与许可目的不同。听歌/下载会员不能作为将歌曲加入导出视频、发布到 B 站/抖音等平台的授权证明。

可核实的一手依据是 [QQ 音乐软件许可及服务协议](https://y.qq.com/i/user_terms.html)：第 2 节给予个人、不可转让及非排他的软件许可，并明确非商业用途；其他未明示权利需另行获得书面许可。协议还限制未经授权的自动程序获取平台内容及第三方自动化操作。因此本项目不应接入非官方的“免费解析/下载全网歌曲”接口。

本次未取得腾讯音乐“启明星”等商用授权服务的有效官方介绍和可调用 API 文档，不对其当前产品入口、曲目覆盖或开放接口作肯定结论。若后续需要流行歌曲，应先明确曲目、导出视频使用方式与发布平台，再对接音乐权利方或其正式商用许可渠道。

## 对当前项目的落地方式

1. 正式成片页仅展示当前配乐摘要和切换/管理入口，避免在线结果与编辑表单长期占用正文空间；试听放在管理弹窗内。
2. 配乐管理弹窗承载本地导入、官网来源入口、可选的 Openverse 搜索、试听、裁剪、音量、速度及应用操作。
3. 官网入口明确表达“前往官网选曲，取得相应用途许可并下载后导入”，不表达为“已接入国内曲库 API”。先链接上述已经核实的首页/栏目，不拼接未经验证的搜索 URL。
4. 音频作为本地受管文件交给现有渲染链路，避免 HyperFrames 成片渲染依赖远端试听地址或第三方登录状态。
5. 后续需要真正的应用内国内曲库搜索时，先获取供应商正式 API 文档、商业接入许可、身份凭据和授权/下载模型，再增加 provider 适配层；源码中不硬编码站内私有接口。
6. 后续素材库可保存标题、作者、来源页、许可类型、许可证明和许可范围，便于复用时判断是否覆盖新项目；下载过一次不代表跨项目无限复用。

以上为产品与技术建议，不代表已实现跨站自动搜索、自动授权或自动下载。
