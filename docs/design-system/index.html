维护流程

  1. 先调整令牌或组件定义，记录版本与影响范围。
  2. npm run design:generate 同步三份生成物。
  3. npm run design:check 校验引用、主题、对比度与生成一致性。
  4. 在共享组件落地，再审查全部调用页面。
  5. 验证主题、键盘、缩放与宽窄窗口，并记录临时例外。
