## 业务状态门槛

2026-10-24 B 站一键发布增量：用户明确要求在已有工作流实现自动上传。实现保留平台、成片、资料与审核顺序；账号/分区/可见性/版权由用户在发布时明确选择。扫码、未登录/过期、参数缺失、未审核、执行中、防重、取消、平台审核中、审核结果、离线结果不明与人工核查均有独立状态。结果不明时不自动重试，确认未投稿提供描述、取消、Escape 与焦点返回；选择按项目保存在本机，切页不中断后台投稿。沿用 VIDEO-WORKFLOW-001 控件例外，无额外布局决策。验证与边界见 [B 站发布验证](video-workflow-bilibili-publishing-verification.md)。

## 已确认的交互决策

| 场景                              | 用户决定（2026-10-22）       | 设计 / 开发要求                                                              |
| --------------------------------- | ---------------------------- | ---------------------------------------------------------------------------- |
| 订阅新增 / 编辑有未保存输入时关闭 | 沿用现状，直接关闭并丢弃修改 | 关闭按钮、Escape、遮罩一致；重开从空表单或已保存订阅恢复，不增加放弃确认     |
| 用户自选主色对比度不足            | 提示不足，但允许用户保存     | 就近说明对比度问题和建议；不阻止保存、不静默改色；默认主题仍按对比度门槛验收 |

订阅预览已覆盖关闭 / 重开。Settings 提供内存主色预览：对比度不足时提示并允许保存，支持明暗 / system 切换与恢复默认，刷新清除。生产主题桥的持久化和完整对比度提示仍须迁移验收；设计稿不读写个人设置。禁用试听的原因就近显示，启用的纯图标动作提供悬浮和键盘焦点 Tooltip。
