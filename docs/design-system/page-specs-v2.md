# UI 2.0 页面交付规格

承接 [设计规范 2.0](spec-v2.md)，适用于设计与开发。真实设计稿在 `v2/`，全部为内存示例。侧栏进入页面；`?page=ai-lab&theme=dark&state=ready` 可直达。评审栏不进入生产界面。

沿用项目主题和现有紧凑桌面布局；HeroUI 自带图标优先，缺项补已确认的 Heroicons。状态门槛、审核证据和待决项见 [交互审核](interaction-audit-v2.md)。不确定业务先确认，示例简化不构成生产删减许可。

## AI Lab item 排版合同

以生产 `src/renderer/modules/ai-lab/components/SubscriptionsPanel.tsx` 与 `ToolDirectory.tsx` 为参照，保留 item 内部信息组织；HeroUI Card 外壳与控件尺寸沿用上游默认。

| item         | 必须沿用的排版                                                                                                                                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 订阅         | 240px 定宽、不拉伸、间距 12px、局部横滚。首行左侧 32px 品牌，旁边套餐名在上 / 服务商在下，右侧编辑与删除在 hover / 键盘焦点时显示。下一行左费用与周期、右日历与续费日期；业务行间距 6px，费用使用紧凑等宽字体。 |
| 订阅可选内容 | 有周期数据时，费用下方保留周期进度及周期 / Token Limit 左右说明；有密钥时，最下方保留密钥图标、掩码与复制动作。字段缺失时省略对应区域，不以“已启用”等无依据状态替代。                                           |
| 工具         | 2 / md:3 / lg:4 列、间距 12px。首行左侧 36px 主色浅底业务图标，右侧名称在上 / 服务商在下；下面为 11px、最多两行的描述；底行左分类、右悬浮 / 焦点箭头。整个 item 可点击，并支持 Enter / Space 和可见焦点。       |

名称为 12px / 16px 加粗，服务商为 10px 辅助文案；长名称单行省略并保留完整可访问名称。业务图标使用已确认来源，不以品牌 Logo 替代工具业务图标。新增订阅示例未填写日期时不生成假续费日期。

本轮独立稿展示基本字段；订阅编辑 / 删除入口仅打开标明“布局预览”的详情，不执行删除。周期进度、密钥栏及完整表单 / 业务仍按生产合同补齐后验收，不能据此删除生产能力。

## AI Voiceover

入口：Video 页头。固定标题与关闭，Tabs 导航“配音 / 我的音色 / 本地模型”；编辑区 + 304px 任务栏，底部试听与主操作。内容独立滚动；窄高和缩放时所有操作可达。

| 分区        | 交互和验证                                                                                                                     |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 配音方式    | RadioGroup 选预设 / 克隆；切换字段集，保留文案                                                                                 |
| 预设        | 语言 / 音色 Select；语速、音调、音量 Slider；加载失败就近重试                                                                  |
| 克隆        | 引擎 / 音色 Select；质量 RadioGroup；高级参数折叠；保留降噪和后台识别                                                          |
| 文案        | Label + TextArea + Description/FieldError；按当前业务去首尾空白，以 Unicode code point 计数，最多 300 字符；空白或超限禁止生成 |
| 我的音色    | 导入 → 后台识别 / 可用 / 失败，重试；OS 文件选择；不强制人工确认转写                                                           |
| 本地模型    | 环境检查 / 未就绪 / 下载 / 可用 / 失败；就近配置入口                                                                           |
| 任务 / 试听 | 排队、生成、完成、失败、已取消；取消 / 重试，单音源互斥，无音频禁用试听                                                        |

设计稿模拟生成、取消、完成和重试；“预览失败”显式触发错误。`?page=video&dialog=voiceover&state=error` 直达失败稿。导入、转写、播放和导出需要后续生产验收，不连接模型、不创建素材文件。

## 添加订阅与通用详情

订阅弹窗仅演示嵌套 Select 和校验，不是完整生产表单。生产须保留 SubscriptionsPanel.tsx 的服务商 / Other、套餐名称、Base URL、API Key、六种周期、开始日期、费用、Token Limit 以及新增 / 编辑 / 删除 / 追踪。费用空值与 0 不同，不能沿用示例必填规则。用户已确认关闭即丢弃未保存修改，不增加确认框；新增重开为空，编辑重开载入已保存值。

详情示例展示内容层级与关闭 / 焦点行为；通知必须保留持久消息语义。模拟保存不可写成生产 IPC 已完成。

## 状态矩阵

| 参数      | 必须呈现                     | 恢复 / 保留                        |
| --------- | ---------------------------- | ---------------------------------- |
| `ready`   | 内容、筛选、单位、更新时间   | 刷新保留输入                       |
| `loading` | Skeleton / Spinner、可读状态 | 保持模块占位                       |
| `empty`   | 原因、下一步                 | 区分无数据、无搜索结果、未连接     |
| `error`   | 错误、重试                   | 保留已载内容与输入，提交失败不关闭 |
| `offline` | 缓存说明、不可用动作         | 本地编辑继续，联网动作禁用或重试   |

生产按数据粒度局部承载状态。设计稿全页示例用于验证通用规则，不能据此将生产局部错误变成整页覆盖。

无账户、缓存过期、模型缺失等必须按 [交互审核](interaction-audit-v2.md) 在具体区域单独设计与验收，未覆盖项不得标记完成交付开发。

## 边界与验收

每页保存明暗 1440px 截图，关键页补 1024px、低高度和 200% 缩放；Voiceover 补预设、克隆、失败、模型未就绪。组件补 focus、Select 展开、嵌套 Escape 和焦点返回。

检查长中英文、零费用 / 用量、未选择、空列表、未知账户、断网和无可用音色。破坏性删除用 AlertDialog；异步防重复；后台任务独立于弹窗开关。

本轮不接埋点，不宣称效率或成功率提升。实际指标在正式迁移后观察加载、失败和任务恢复。
