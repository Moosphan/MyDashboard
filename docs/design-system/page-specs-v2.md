# UI 2.0 页面交付规格

承接 [设计规范 2.0](spec-v2.md)，适用于设计与开发。真实设计稿在 `v2/`，全部为内存示例。侧栏进入页面；`?page=ai-lab&theme=dark&state=ready` 可直达。评审栏不进入生产界面。

沿用项目主题和现有紧凑桌面布局；HeroUI 自带图标优先，缺项补已确认的 Heroicons。状态门槛、审核证据和待决项见 [交互审核](interaction-audit-v2.md)。不确定业务先确认，示例简化不构成生产删减许可。

名称为 12px / 16px 加粗，服务商为 10px 辅助文案；长名称单行省略并保留完整可访问名称。业务图标使用已确认来源，不以品牌 Logo 替代工具业务图标。新增订阅示例未填写日期时不生成假续费日期。

本轮独立稿展示基本字段；订阅编辑 / 删除入口仅打开标明“布局预览”的详情，不执行删除。周期进度、密钥栏及完整表单 / 业务仍按生产合同补齐后验收，不能据此删除生产能力。

## 视频创作工作流增量合同（2026-10-23）

用户指定 [视频工作流 UI 规格](video-workflow-ui-spec.md) 及其高保真稿作为本功能的布局基线。组件继续使用现有 React 18 / Radix 与项目主题，HeroUI 迁移在其他分支执行；该例外不允许改变页面排版。

- 项目列表：页头 → 四项概况 → 搜索/筛选 → 横向项目行；行内按缩略图、项目信息、阶段状态、继续创作排列。
- 项目列表控件修订（2026-10-23 用户截图授权）：搜索框局部采用 40px 高、8px 圆角、12px 水平内距；状态筛选去除可见“项目状态”标签，保留可访问名称。搜索、状态、查看归档与执行环境按钮垂直居中，后两者为 40px 图标按钮并提供名称/悬浮说明，归档视图标记按下状态。项目行保留继续创作，归档/恢复移入末尾“更多操作”图标触发的既有 Radix popup 菜单；Space 打开、方向键选择、Escape 关闭并返回触发器。执行中任务仍禁止归档。沿用既有 760px 断点，窄窗口搜索独占首行，筛选和两个图标同处第二行，避免各按钮占满整行。不改变其他页面 Input 或项目条目内容顺序。
- 详情：返回/项目名/规格，右上环境/历史 → 八阶段 Stepview → 主产物与审核侧栏 → 底部版本提示与下一步；不重复添加 Video Studio 大页头。
- 用户间距修订（2026-10-23）：详情页模块间距 16px；返回按钮去除水平内距，图标与项目标题、主卡片左缘对齐；步骤内部间距 4px、底部内距 12px，四列两行时行距 16px。保留按钮垂直点击范围、步骤圆点尺寸与连接线位置，不改变全局页面内距。
- 1024px 及以上八列步骤；主区右栏 240px，1024–1199px 为 224px/16px 间距；小于1024px四列两行并将审核放到内容下方。
- 分镜：标题/创作设置 → 16:9主预览 → 当前镜信息 → 缩略图 → 屏幕文字/口播；创作设置、单镜编辑均使用可取消弹窗。
- 分镜内置 MG（2026-10-24 用户授权）：在既有创作设置增加“Motion graphics 动画”开关，开启时可展开按稳定分镜 ID 排除页面；开关和排除随版本保存，取消不生效。未设置的历史项目沿用原创作要求，显式关闭不应用 MG。开启后本地 Agent 自动创建未排除页的独立元素与归一化动效计划，即使选择视觉模板也经 Agent 编排；生成仍为待审核版本。原预览保持静态关键帧，在相同主栏内显示计划就绪数量、当前镜计划详情及素材缺口，不新增补齐入口。缺少计划/实际目标或素材时在分镜审核前阻止推进，粗剪按实测配音时长复用。文案、口播、配音不自动重做，旧版保留；重用沿既有流程。保留主题、布局、审核位置与键盘焦点返回。
- 口播：分镜选择 → 口播正文 → 读音提示。配音：引擎/音色 → 段落列表。发布：平台选择 → 共用成片 → 当前平台资料。
- 配音增量（2026-10-23 用户授权）：成功一段即显示并可试听，任务级片段持久保存；显示实际完成段数与总段数、当前处理阶段，合并校验前仍为执行中。失败/取消/中断保留成功片段，不能将片段作为完整版本审核；旧完整版本和当前任务片段明确区分，上游变化隐藏过期片段。追加片段不重建已有播放器。播放时标题与播放/暂停按钮采用主题主色，暂停、结束、错误或切换其他音源时同步还原；保留加载、错误、键盘播放、可访问进度与静音，不自动播放新片段。主布局及审核推进位置保持原合同。
- 配音停顿与单段重生成（2026-10-24 用户授权）：VoxCPM2 高级参数提供“参考尾部停顿（毫秒）”，默认 320、范围 0–1000、步进 10，0 表示关闭；只改变临时续说提示，不截取生成结果。逐段播放器右侧提供“更多操作 → 重新生成此段配音”，复用当前冻结引擎、音色和参数，仅替换所选 `file.id` 片段；同一镜拆出的其他片段保持不变。成功创建新的待审核完整配音并使下游失效，失败/取消保留旧版本；任务运行时禁用并就近说明。原生 `audio controls`、段落标题→时长→正文→播放控制顺序保持不变。
- 配音文件定位（2026-10-24 用户追加）：逐段播放器“更多操作”菜单提供“打开所在文件夹”，先校验文件仍属于当前项目且内容指纹未变化，再由 Electron 在系统文件管理器中定位该文件；文件缺失或校验失败就近显示错误，不泄露未经校验的路径。
- 播放器纠偏（同日用户最新要求）：恢复先前原生 `audio controls` 的灰色胶囊、时间/进度条/音量/菜单布局；所有进度条保持原生中性色，未播放按钮保持原样。仅正在播放的按钮增加主题色圆形背景，段落标题使用主题主色并明确加粗为 700；不再显示带“播放/暂停”文字的项目色按钮。暂停、结束及互斥切换同时还原标题和播放按钮。
- 文案 AI 入口（2026-10-24 用户授权）：内容文案标题右侧放置主按钮“AI 生成文案 / AI 重新生成文案”，在文案编辑框上方常驻“文案创作要求 / 修改建议（选填）”（最多 5000 字符），展示简报版本、目标时长与当前本地执行器。直接在工作台调用 Codex / Claude Code，无需外部生成和粘贴；沿用右侧执行器与导入/导出，去除右侧重复生成按钮。初稿基于已审核简报，修改稿同时使用当前已保存文案与建议，返回完整文案。有未保存修改先保存或放弃，执行中锁定编辑和建议，主按钮显示生成状态，真实进度与取消入口沿用执行日志。失败/取消保留原文和建议，成功创建待审核新版本并保留历史、使下游产物失效；不自动审核或推进。保留既有分栏、审核与底部动作，窄视口标题按钮可换行。
- 口播 AI 入口（2026-10-23）：编辑区标题右侧“AI 生成口播稿 / AI 重新生成口播稿”，就近展示文案与分镜版本、镜数和目标时长。沿用右侧本地执行器选择与导入/导出；不重复展示生成按钮。全部前置阶段已审核才允许生成，有未保存修改时先保存或放弃；执行中锁定口播编辑并通过任务日志显示加载/阶段。生成后逐镜人工审核，审核通过才允许进入配音。
- 单镜口播及修改记录（2026-10-24 用户追加）：完整生成按钮明确“全部”；当前分镜选择后提供“AI 仅重新生成当前镜口播”，稳定 ID/顺序一致时仅替换该镜正文和读音，其他镜原样保留。前序修改导致口播过期时提供“沿用现有口播稿”，不调用 AI，关联当前已审核输入并创建待审核版本；镜数或顺序变化时明确要求完整生成。单镜/沿用均保留未保存保护、执行锁定及审核。任务记录区分全量、单镜、人工修改与沿用，展示真实目标、用户意见和来源/结果版本，详情可展开逐字段修改前后（HTML 以纯文本展示），不补造旧任务的修改细节。保留现有主栏、口播字段顺序及右栏位置。
- 发布 AI 入口（2026-10-23 用户追加）：保持平台选择→共用成片→当前平台资料顺序，在资料标题右侧提供“AI 生成发布资料 / AI 重新生成发布资料”；就近显示文案、分镜、口播来源版本。可展开填写生成偏好与修改要求，各平台分别保留当前要求；一次只替换当前平台的标题、简介和标签，另一平台不变。沿用右侧本地 CLI 执行器、任务日志及任务导入/导出；未保存修改时先保存或放弃，执行中锁定资料和平台选择，展示真实加载/取消/错误/重试。成功创建待审核新版本并保留历史，失败保留旧资料，人工编辑与审核后才可导出发布包。提示词提炼相关话题和搜索关键词，不自动获取实时热搜，不编造热度或超出视频内容的结论。
- 审核为右侧 Card，任务为分隔线后的低权重区域；保存及下一步在底部，不合并“审核并自动生成”。未保存草稿阻止审核和推进。
- 右栏增量授权（2026-10-23）：用户要求重设计信息与执行记录。审核资料采用标签/值对齐；执行记录采用紧凑时间线，展示任务名称、结果、真实开始时间、执行器、耗时及最新处理阶段。执行中优先，加载动画与不定进度条不提供虚构百分比；耗时每秒刷新，阶段变更通过 live region 宣布。
- 记录默认最近三条，可展开当前阶段其余记录；日志区域限高局部滚动，不挤走任务操作。任务 ID、结束/更新时间与完整错误通过原生 details 展开，支持键盘，长错误独立滚动。成功仅代表执行完成，仍须人工审核；不推断或补造历史阶段事件。主产物、分栏宽度、断点、审核门禁和底部动作沿用原合同。
- 用户确认的粗剪修改闭环（2026-10-23）：在现有预览与逐镜信息之后，以可展开区域提供当前镜/整片、播放器真实时间、自然语言意见和本地执行器。先生成并展示计划（镜头、目标、时间范围、意见），人工确认才合成新粗剪；旧版保留可预览，新版需审核。只改动效保留已审核文案、口播、配音，成片与发布状态失效；涉及上游内容时明确提示回对应阶段修改。计划绑定项目版本，失效后不能应用；运行/失败/取消复用执行日志。
- 粗剪动画修改与定位修复（2026-10-24）：修改基于预览视频实际来源的分镜、口播和配音，沿用原 MG 开关与排除设置；即使上游已有新版本，也不混入未应用的内容。可直接修改已有元素的透明度、位移、等比或方向缩放、旋转、入场节奏和镜间转场；新增元素、改文字或换素材仍回分镜阶段。历史创作要求仅作为本次修改的背景，单镜计划不强制补齐其他镜头或历史未实现要求；首次生成仍落实完整创作要求。分镜定位统一按实测时长建立时间轴，跳到目标镜在 30 fps 视频中的首个有效帧，定位期间不让旧播放事件覆盖选中项；标题和口播随稳定选中镜同步，原生进度条与正常播放仍更新选中镜。保留布局、主题、修改区和人工确认入口。
- 取消动效计划与沿用原视频（2026-10-24 用户纠偏）：仅在原修改区提供“取消修改计划”，撤销未应用的计划并清空本地意见草稿，焦点回修改区标题；不新增静态合成按钮。取消后保留当前预览视频的文件、版本、画面、原配音、字幕及实测时长，若原粗剪因后续输入变化失效，在校验文件及冻结工程指纹后恢复为待审核；使用原“审核通过此版本”进入正式成片。保留实际来源版本，不将后续上游修改声称为已应用；不改上游审核，不自动审核粗剪，不重新合成视频。沿用行为写入执行记录，正片按这份冻结工程的原时长及来源输出。后续上游再修改仍正常失效。
- 分镜 AI 修改入口（2026-10-24）：在“修改此分镜”对话框保留人工编辑，并增加自然语言修改意见；本地 Agent 仅返回当前分镜并保留其 ID，服务端合并后创建待审核分镜版本，其他分镜和已审核版本保持不变。执行中显示真实任务状态，失败保留原分镜和修改意见；成功后回到分镜安全预览，需人工审核通过才进入口播。
- 动效确认提示纠偏（2026-10-23）：计划完成不代表视频更新。预览区域使用现有提示样式明确旧视频版本与目标版本，提供定位原有计划确认区的入口；待确认计划自动展开，显示覆盖镜数、元素动效和显式转场。执行记录使用“计划已生成”区分视频合成完成；不得自动确认或自动审核。当前镜只改变指定镜，整片修改需显式选择整片。转场支持叠化、横向/纵向推移、擦除及直接切换，保持配音、字幕和全片总时长；不新增时间轴编辑器或改变主体布局。
- 正片工具区增加“保存为模板”及可取消弹窗：正片审核通过才可保存名称、选填风格描述、多镜样式样本和已有动效；新项目在分镜“创作设置 / 我的模板”选择后由本地 Agent 结合新文案重排。静态来源明确不包含元素动效。模板是视觉样本参考，不承诺任意 HTML 自动转换成完全参数化组件。另可导出可编辑工程副本给 HyperFrames Studio，不修改已审核工程；本期无 Studio 修改自动回导。弹窗支持 Escape、焦点返回与错误保留输入，布局和底部审核位置不变。

## AI Voiceover

视频工作流分段配音版本增量（2026-10-24 用户追加）：音频面板沿用现有工作流信息顺序，增加“当前/历史 vN · 生成时间”选择器；历史版本可试听，来源可核实、口播正文/读音/分镜 ID 与顺序一致且文件完整时可“切换为当前版本”，切换创建待审核新版本并使下游产物失效。仅视觉修改导致配音过期时，右侧原审核按钮显示“沿用并审核此版配音”，确认弹窗说明校验文件、沿用旧音频创建并审核新版本；旧版继续保留，执行记录展示来源/结果版本。内容变化或文件校验失败时禁止沿用，不自动生成或审核。Qwen3 Base 继续使用冻结 `ref_audio + ref_text`，工作流按片段派生随机种子，单段重生成加入任务盐值，避免异常片段固定复现；不新增模型入口或改变审核动作位置。

本地模型环境恢复（2026-10-24 用户追加）：首次读取自动检测；检测结果按配置、平台、二进制、模型与 Python 包元数据持久缓存，重启后环境未变化直接恢复。环境变化自动重新检测，手动检测仍强制重检，并发请求共享同一次检测。沿用现有本地模型页字段及状态，不增加人工检查前置步骤。

工作流错误详情增量（2026-10-24 用户授权）：执行记录的完整错误文本支持鼠标选中及系统复制快捷键，并在展开详情内提供“复制错误信息”按钮。复制完整原文，保留换行；复制成功显示“已复制”，失败保留错误并提示可选中文字复制。按钮支持 Tab、Space / Enter，复制中防重复；不改变执行记录顺序、审核门禁和主布局。

音色导入增量（2026-10-23 用户授权）：在“我的音色”导入草稿内展示原录音真实波形，拖动边界或平移选区截取连续 3–30 秒，默认选前 15 秒以内。支持时间轴缩放、方向键 0.1 秒 / Shift 1 秒和 0.01 秒时间输入；试听、后台识别、保存均针对当前选段。拖动结束后自动识别，范围改变停止旧选段试听并清除旧转写。保留原录音，仅用保存的选段克隆。保留工作流入口与现有面板布局。

入口：Video 页头。固定标题与关闭，Tabs 导航“配音 / 我的音色 / 本地模型”；编辑区 + 304px 任务栏，底部试听与主操作。内容独立滚动；窄高和缩放时所有操作可达。

## 状态矩阵

## 边界与验收

每页保存明暗 1440px 截图，关键页补 1024px、低高度和 200% 缩放；Voiceover 补预设、克隆、失败、模型未就绪。组件补 focus、Select 展开、嵌套 Escape 和焦点返回。

检查长中英文、零费用 / 用量、未选择、空列表、未知账户、断网和无可用音色。破坏性删除用 AlertDialog；异步防重复；后台任务独立于弹窗开关。

本轮不接埋点，不宣称效率或成功率提升。实际指标在正式迁移后观察加载、失败和任务恢复。
