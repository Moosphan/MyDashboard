# 史笺 · 历史文化模板验证

## 使用

视频工作流 → HTML 分镜 → 创作设置 → 套用视觉模板 → **史笺 · 历史文化**。

应用后保存草稿、审核新版本，再继续原工作流。切换模板替换旧 HTML，保留标题、正文、ID、顺序；不自动生成、审核或覆盖已有视频。十种版式通过原“修改此分镜 / 本镜布局”选择，创作设置展示全部十页样本。编年正文可写成 `前138年｜张骞首次出使西域`，前段作为节点标签；其他版式也可用 `主题｜说明` 组织分栏。无标签时使用阅读序号，不猜年代或来源。

十种版式：卷首山川、人物与背景、编年脉络、双栏辨析、文本细读、结语索引、山川行旅、人物关系、器物解读、章节过渡。新增四种分别提供路线与节点、主题关联线、可拆解器形与说明、大字章节转场。路线标注“路线示意 · 非比例地图”，器形标注“原创器形示意 · 非实物复原”；不据普通段落推断地名、人名或历史关系。模板规划轮换使用十种，Agent 获得全部布局和适用规则；其他模板族保留原六种。

MG 开关沿用当前用户设置，不自动开启。开启后由现有 Agent 路径按内置视觉源生成对应的真实元素与结构化计划，仍需审核；不使用随机 CSS 动画。关闭时是静态模板。真实照片、文物、地图按内容另行提供，不以装饰山川冒充。

## 证据

- `pnpm test:video-workflow`：本轮 66 项通过；包含合法载荷、十版式、内容与转义、无网络依赖、长文提示、十种布局规划和 Agent 视觉合同。
- `pnpm test:history-template`：Electron 截取十页示例及每页 32 字标题（新增四种用 48 字）搭配 90/180 字正文，另有路线、关系、器物的四节点长标签，共 33 页；检查正文位于字幕安全区以上且不横溢，输出 `.scratch/history-template/verification.json` 与 PNG。总览使用缩小的独立缩略图，避免同时解码十张 Retina 原图。
- `pnpm test:history-template:ui`：真实生产入口，临时独立数据目录。明暗主题、1440/1024、200% 缩放、Space 选择、Tab 焦点限制、Escape 取消与焦点返回、应用与保存草稿通过；验证十页样本、十个布局选项、键盘切换器物布局并保存、旧自定义 HTML 实际替换，以及其他镜和文案阶段不变。
- `pnpm design:check`、`pnpm design:build`、`pnpm build` 通过。
- macOS arm64 未签名目录包实际启动，`app.isPackaged=true`；十页样本、模板选择、取消、保存、明暗、强制高对比和减少动态效果模式通过。产物 `/tmp/history-template-packaged/mac-arm64/MyDashboard.app`，仅用于本地验证。
- 主墨色、朱砂文字、茶褐文字相对最深纸底的对比度分别 8.57:1、4.72:1、4.74:1；淡色山川和细线为装饰，不承载正文。
- 类型检查与前一版归一化行号对比未新增诊断；全仓原有类型错误仍存在，不声称全仓类型通过。

再现展示稿：`pnpm exec tsx scripts/preview-history-template.ts`，打开 `.scratch/history-template/index.html`。展示稿中关于丝路的文字仅是模板样例，不会写入用户项目。

## 边界

静态模板每镜正文最多 180 字、标题 48 字、内容 6 段；编年、路线、关系、器物页最多 4 节点，超过时提示拆镜，不截断文字。自动模板规划仍按每镜 90 字拆分。复杂史料或长标题可改用 Agent 排版。系统字体随平台不同可能有差异；本次在 macOS Electron 验证宋体回退。

此次没有运行用户项目的付费 Agent 任务、配音或成片生成，不修改历史项目产物。
