# 正式成片配乐管理弹窗验证

日期：2026-10-26。授权依据：用户要求将配乐集中到弹窗，正片页只做展示、选择与切换，并询问国内曲库。

## 实现边界

- `MediaPanels.tsx / MusicPanel`：保留当前视频、版本选择、分镜、审核与底部动作；主区展示已应用曲目与参数摘要，可选择本项目历史成片配乐及本次导入音频。选择尚未应用时明确提示，只有显式应用才调用既有正式成片生成流程。
- 复用 `WorkflowDialog` 与已有 Button、Select、Voice 字段和原生媒体，沿用 `VIDEO-WORKFLOW-001` 的 React 18/Radix 例外。无新依赖、图标、主题或全局 CSS。
- 弹窗包含本地导入、国内官网入口、可折叠 Openverse 搜索、试听与裁剪/音量/速度；关闭保留本次页面草稿并卸载试听。相同成片数据刷新不重置草稿，成片文件改变后重新载入对应版本。草稿不承诺重启后恢复；应用过的配乐随历史版本持久保存。
- 官网来源：爱给网、100Audio、猴子音悦；按钮通过现有 Electron 系统浏览器入口打开已核实的固定 HTTPS URL。官网选曲、取得适用授权并下载后本地导入，未实现国内曲库站内 API 搜索/下载。证据与覆盖限制见 [调研](chinese-music-library-research.md)。

## 状态与键盘

| 场景 | 行为 |
| --- | --- |
| 无配乐 | 紧凑空状态与管理入口，主区不挂载音频播放器或编辑表单 |
| 有配乐/选择待应用 | 摘要显示实际成片参数，草稿另行标注；下拉支持无配乐和已有音频 |
| 关闭/重开 | 保留选曲和数值，关闭不渲染，Escape/关闭按钮返回入口焦点 |
| 请求中 | 禁用编辑与重复应用，关闭不隐式取消后台请求 |
| 失败/离线 | 沿用就近错误与执行记录，失败保留参数；官网打开失败显示原因 |
| 历史预览/任务锁定 | 可打开查看，编辑与应用禁用并说明原因 |
| 试听 | 与页面其他媒体互斥，关闭弹窗卸载音频 |
| 键盘 | Tab 限制在弹窗，Escape 关闭，Slider 方向键改变数值；Select 支持 Space、Home/End、Enter |
