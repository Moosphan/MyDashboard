# Toolbox 登录持久化与字段读取修复

目标：修复加载时字段尚未就绪导致的失败；使用系统凭据存储保护的加密文件恢复 Cookie、服务关联和最近成功用量；图标改为纸飞机。

用户此次要求替代原方案的“用量仅内存缓存”。官网密码、订阅地址和整页 HTML 仍不保存。

- [x] 先在真实 Electron 会话中用延迟渲染的官网响应复现 unsupported，再让登录确认和后台读取等待有效字段。保留登录、安全检查和目标服务校验。
- [x] 新增仅主进程访问的加密缓存。Chromium 始终使用隔离的内存分区；Cookie 变化同步写入原子替换的加密文件，恢复时先加载 Cookie 再访问官网。系统加密不可用时禁止明文保存。
- [x] 用量与成功时间绑定所选服务写入同一加密缓存，重启先显示缓存，刷新失败仍保留；更换服务或退出清除旧缓存。验证跨进程恢复、密文无令牌、损坏文件和退出清理。
- [x] 使用现有 Material Symbols 的 send 纸飞机，更新登录隐私说明、缓存状态及不滚动布局验证。
- [x] 运行针对性测试、生产构建、ESLint、Electron 界面与跨进程重启验证；重启本地应用并说明旧临时登录需重新登录一次。
