# 配音沿用与本地环境缓存实施计划

**目标：** 口播未变化时可直接沿用并审核旧配音；重启后无需手动重复检测本地环境。

**约束：** 沿用当前 workflow worktree、布局及 VIDEO-WORKFLOW-001；不重生成用户配音、不绕过人工审核，不把过期标记直接改成已通过。

1. 添加失败回归：视觉修改→沿用/审核口播→直接审核旧音频；口播/文件变化拒绝沿用；环境检测后重建 manager 恢复状态。
2. 从配音保存时的历史快照核实来源口播，逐镜比较 ID/顺序、正文、读音，校验文件后创建新配音版本并在用户审核动作内通过，保留旧版本及操作记录。
3. 在 AudioPanel / StageWorkspace 展示可沿用状态，兼容历史版本恢复；禁止改变内容的旧配音继续通过。
4. RuntimeManager 保存检测结果及配置/平台/工具/模型/包元数据指纹；读取、生成自动确保检测，配置或文件变化自动失效；保留手动强制重检与并发去重。
5. 执行 workflow / voiceover 回归及真实 Electron，检查明暗、键盘、缩放、设计构建及类型诊断，重启实际应用。
