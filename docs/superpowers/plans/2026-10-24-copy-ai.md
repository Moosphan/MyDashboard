# 工作台文案 AI 生成与修改 Implementation Plan

> **For agentic workers:** Use executing-plans to implement this plan inline, with tests before implementation.

**Goal:** 在内容文案编辑区直接生成文案，并根据用户修改建议反复生成待审核版本。

**Architecture:** 复用现有本地 Codex / Claude Code、IPC、版本和执行日志。新增文案提示词模块，将已审核简报、已保存文案和受长度限制的修改建议传给执行器；导出任务使用同一提示词。

**Tech Stack:** 现有 React 18、Radix、项目主题、Electron、TypeScript、SQLite。

## Global Constraints

- 遵守设计规范 2.0 与 VIDEO-WORKFLOW-001，保留分栏、审核与底部操作，沿用既有组件。
- 用户已明确授权将生成主操作移动到文案编辑区，并增加修改建议；右侧不重复生成入口，保留执行器与导入导出。
- 有未保存修改时先保存或放弃；执行中锁定文案和建议，以真实日志和不定进度显示状态。
- 成功创建待审核版本、保留历史；失败/取消保留旧文案，不自动推进流程。
