# 抖音投稿与播放按钮实施计划

目标：封面播放按钮改为半透明黑色圆底与浅色图标；接入 Catbus 抖音扫码、多账号、视频投稿与回执核查。

范围与依据：Catbus 0.2.1 的 `douyin/web/commands.js`、`normalize.js` 与平台能力定义。抖音身份使用 sec_uid；视频 ID 为数字。支持视频、封面、标题、简介、标签和可见性，不支持 B 站分区/转载来源参数。分区、类型、来源继续保存与导出，页面解释自动投稿能力边界。

约束：沿用 VIDEO-WORKFLOW-001 控件例外与现有桌面布局；保留 B 站账号和投稿历史及旧 IPC。不自动审核或实际投稿用户作品。所有文件编辑用 apply_patch，不创建提交。

1. 先增加抖音服务测试，覆盖 sec_uid、平台隔离、投稿参数、已审核版本、私密状态、取消、未知结果及回执归属，运行确认缺失行为失败。
2. 将现有账号索引、Catbus 适配器和投稿服务按平台参数复用，保留 B 站默认值/导出名；抖音单独索引、凭据目录、投稿表和迁移，不共用账号或请求幂等键。
3. 工作流生命周期初始化和释放抖音服务，添加抖音 IPC 与受验证的作品链接打开能力。
4. 复用现有账号弹窗与投稿面板，按平台展示应用名、身份、设置和记录。保留抖音原导出/回填，支持明确扫码取消与解绑确认。
5. 更新播放按钮、页面规格与迁移记录。验证服务、工作流回归、生产构建、设计资产、类型基线、Electron 主题/视口/键盘/缩放和打包运行。
