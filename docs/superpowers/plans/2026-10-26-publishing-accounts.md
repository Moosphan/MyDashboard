# 发布预览与 B 站多账号实施计划

目标：重新设计封面播放入口，并在账号管理弹窗中支持多个独立 B 站登录及切换。

约束：沿用 VIDEO-WORKFLOW-001 的 React 18 / Radix 例外、主题和原页面布局；不改变抖音手工发布；不自动登录、审核或投稿生产项目。

1. 在 `scripts/test-bilibili-publishing.ts` 添加真实子进程测试：旧账号恢复、新增账号、切换与重启恢复、取消扫码、重复 UID、错误 UID 与投稿历史账号隔离。先观察失败再实现。
2. 新增 `src/main/services/video-workflow/bilibili-accounts.ts` 保存不含凭据的账号索引，每个新账号使用独立 Catbus home，旧 home 原样兼容。成功扫码才登记，失败或取消清理临时 home。
3. 更新 `bilibili.ts`、`catbus.ts`、共享类型和 IPC：切换前验证真实 UID，投稿冻结原账号，历史查询按原 UID 寻找凭据；运行中的登录、上传与核查阻止账号切换或删除。
4. 新增 `BilibiliAccountsDialog.tsx` 封装绑定列表、扫码、切换、解除确认与错误重试，原发布面板仅保留当前账号摘要和管理入口。关闭弹窗不取消扫码，重开可继续。
5. 新增 `VideoPreviewButton.tsx` 作为专用媒体覆盖入口，使用 Heroicons 的三角播放图标、半透明白色及深色细描边，保留命名、40px 点击范围、键盘焦点和弹窗播放逻辑。
6. 运行后端、Electron 页面、明暗封面、键盘、1024/1440 与 200% 缩放验证；执行构建、受影响文件格式和 lint、设计检查及类型基线比较，更新设计合同及验证记录。

不在本次任务中自动提交或推送新增改动。
