# 视频工作流实施计划

分支：`feature/video_studio_workflow`。用户已明确批准生产改版，并要求沿用现有 React 18、Tailwind 3 和 UI 组件；HeroUI 迁移在独立分支执行。

1. 持久化项目、不可变阶段版本、精确版本审核、失效链和可恢复任务。
2. 本地 CLI 与人工导入，模板族的逐镜布局及 Agent 自由创作。
3. 复用现有配音队列，冻结逐镜音频、字幕和真实时长。
4. 将已审核 HTML 安全栅格化，生成冻结 HyperFrames 工程，粗剪审核后渲染成片。
5. 两平台独立元数据、导出发布包及人工发布记录。
6. 使用现有组件实现项目列表、Stepview、编辑预览与人工审核；验证状态机、构建及 Electron 界面。

约束：不自动审批；不自动发布；不迁移全局 UI；不把生成中的进度伪造为百分比；外部工具缺失时保留人工导入通道和具体错误。
