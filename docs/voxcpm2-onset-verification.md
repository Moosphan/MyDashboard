# VoxCPM2 句首额外发声排查

## 复现记录

- 生成任务：`24ece3e2-cc05-43c0-9539-cb4702ed021d`。
- 模型：`mlx-community/VoxCPM2-8bit`，revision `d52725898a0675703f7f9ddc5a4d1a3cdbb99032`，mlx-audio `0.6.1`。
- 音色：银月音色 v1，参考文字「有时是灵动可爱的少女。」。
- 参数：seed `643025039`、10 steps、CFG 2、参考降噪开启。
- 降噪参考 SHA-256：`b8573ac969437c4333489ce8536faed415db317b675a9033e971465605d5b541`。

## 原因与对照

现有适配器同时提供 `ref_audio`、`prompt_audio` 和 `prompt_text`，启用音色参考加语音续说模式。参考片段为 3.60625 秒，最后 100 毫秒 RMS 为 -16.66 dBFS，最后 50 毫秒为 -15.63 dBFS；片段在仍有明显声音时结束。续说模型以这个尾音为起点，容易在新文案前继续发声。

保持原文案、参考音频、随机种子和推理参数，原调用重新生成的前三秒与原始 `raw.wav` 波形相关系数为 1.0，复现了原来的起始声音。仅用 `prompt_audio` 的续说模式仍有额外短音。

仅用 `ref_audio` 的独立克隆模式改善起始声音，但语速和音色变化明显：完整文案从 32.32 秒变为 20.16 秒，CAMPPlus 与同一参考的余弦相似度由约 0.661 降至 0.492。最终没有采用此方案。

保留原来的音色参考及续说模式，只在临时续说提示音频末尾补 320 毫秒静音。相同参数的开头对照中，Whisper Small 首秒识别为「自控的」；未补停顿的首秒无法稳定识别出文案。8.8 秒开头对照的 CAMPPlus 相似度为 0.655，原调用为 0.680。余弦相似度仅作相同工具下的对照，不是音色准确率或主观试听结论。

## 实现与验证

`resources/voice-runtime/adapters/voxcpm2.py` 保留原始 `ref_audio`，为 `prompt_audio` 创建临时 PCM WAV 副本并追加 320 毫秒静音。源文件、参考文字、待合成文字和原推理参数不变。临时文件在生成结束或抛出异常时清理。

应用保存的参考录音为 PCM WAV；普通参考为 24 kHz，ZipEnhancer 降噪参考为 16 kHz。新增测试覆盖两种采样率下原始 PCM 数据与采样率保留、静音追加、参数传递、源文件不被改写及成功/异常清理。

- `pnpm test:voice-runtime`：2 项测试通过，包含 16/24 kHz 子用例。
- `pnpm test:voiceover`：28 项测试通过。
- 通过真实 Python Worker 重新生成同一份完整文案：48 kHz、33.92017 秒，耗时约 69 秒；输出位于 `/Users/dorck/Downloads/银月音色_VoxCPM2保留音色修复/output.wav`。
- 完整样本 Whisper Small 转写从「自控的核心动作」覆盖至末句「并诱导神经可塑性变化」，未识别到句首额外台词。转写存在同音字误识别，不能据此宣称每个字发音均正确。
- 完整样本 CAMPPlus 相似度为 0.704，原始完整样本为 0.661；指标支持这次修改没有出现独立参考模式中的相似度下降，主观音色仍需试听。
- 没有对生成音频做固定时长截头或删词处理。
- 本地开发应用每个任务启动新的 Python Worker，后续任务可直接加载资源文件中的修复。

验证局限：这是一条明确复现案例的修复，不能保证消除所有参考录音、文案及随机种子下的模型额外发声。完整音频的主观音色仍需试听确认。
