MyDashboard voice runtime resource inventory

Distributed resources: worker.py, adapters/voxcpm2.py, adapters/qwen3.py,
transcribe.py, denoise.py, requirements-mlx.txt, requirements-denoiser.txt
and this inventory.

The adapters invoke separately installed MLX Audio (MIT), MLX (MIT), and
user-provided VoxCPM2 / Qwen3-TTS model weights (model cards: Apache-2.0).
Python, FFmpeg, third-party Python packages and model weights are not bundled.
Automatic reference transcription invokes separately installed MLX Whisper
(MIT), using user-provided multilingual Whisper Small weights (MIT).
Optional reference denoising invokes separately installed ModelScope
(Apache-2.0), PyTorch / torchaudio (BSD-style licenses), and user-provided
ZipEnhancer weights (model card: Apache-2.0), in an isolated environment.
It uses VoxCPM's ZipEnhancer pipeline and -20 LUFS normalization for both
cloning engines. Qwen3-TTS has no native denoising flag.
